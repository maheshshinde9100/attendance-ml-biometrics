# attendance-ml-biometrics

* **Automated Face Recognition:** Utilizes computer vision to automatically detect and log student attendance via live webcam frames.
* **Instant Biometric Mapping:** Extracts unique 128-dimensional facial signatures to register and match students instantly.
* **Real-time UX Feedback:** Triggers immediate browser pop-up notifications containing the recognized student's name upon successful check-in.
* **Cloud Ready Integration:** Built completely within Google Colab, leveraging high-performance Python ML libraries and custom JavaScript API web bridges.
* **Persistent Digital Ledger:** Generates structured attendance sheets with localized timestamps for simple administrative oversight.
